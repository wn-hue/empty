# Shift_calander 디자인 테스트

첫 페이지를 흰색·회색 중심으로 정리한 테스트 버전입니다. 주간은 연노랑, 야간은 연보라, 휴무는 회색 글자로 구분합니다. 운영 저장소 wn-hue/shift_cal에는 적용하지 않았습니다.

## 확인 방법

정적 서버로 index.html을 열거나 이 저장소를 별도 Vercel 프로젝트로 연결하세요. GitHub에 저장하는 것만으로 공개 페이지가 생성되지는 않습니다.

근무표·급여 계산·메모는 브라우저 저장으로 테스트할 수 있습니다. 운영 앱과 다른 도메인을 사용하므로 기기 저장 데이터가 분리됩니다.

Google 계정 저장 및 캘린더 동기화는 Vercel 서버와 별도 환경변수/OAuth 리디렉션 주소 설정이 필요합니다. 기존 운영 APP_URL을 테스트 프로젝트에 그대로 넣지 마세요. 설정 방법은 api/google-calendar.js의 환경변수와 운영 저장소의 GOOGLE_CALENDAR_SETUP.md, GOOGLE_ACCOUNT_STORAGE.md를 참고하세요. 인증정보는 저장소에 커밋하지 마세요.
