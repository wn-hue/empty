기존에 사용자 요청으로 제거된 급여 순위, 연차로 연휴 만들기, 함께 쉬는 날, ICS 내보내기는 새 화면에 재노출하지 않습니다. 저장 형식 호환성을 위한 기존 모듈은 남겨 두었습니다.

## 화면 구조

- **근무**: 오늘·내일 → 월 달력 → 월간 요약과 다음 근무. PC에서는 요약을 오른쪽에 표시.
- **급여**: 지급 총액 → 선택적 공제 → 출근·수당 입력 → 읽기 전용 시급 → 상세 내역.
- **식단**: 식단 날짜와 상태 → 네 끼 → 추가 식단.
- **내 공간**: 계정 → 교대조 → 연차·문자 설정 → 화면 환경·내 캘린더·안내.
- 변경은 미리보기 후 명시적 적용. 문자 입력은 자동 포커스로 키보드/확대를 유발하지 않음.

UI 상태는 `studio.css`, 읽기 전용 요약은 `studio.js`, 로그인 설정 오류 처리는 `studio-access.js`에 분리했습니다. 계산·저장·API 엔진은 교체하지 않았습니다. `test-preserved-engine.cjs`는 계산 스크립트와 11개 도메인 모듈의 원본 해시를 비교합니다.

## 운영 제한

`empty`의 Google/Apple OAuth 및 Blob 환경변수가 비어 있어 실제 계정 로그인, 클라우드 저장, 실시간 링크 공유는 아직 운영 연결되지 않았습니다. 기능 코드와 모의 서버 검증을 제공하며 성공을 가장하지 않습니다. 설정 방법은 `SETUP.md`를 참고하세요. 개인 캘린더/AlarmKit과 설치 서명은 기기에서 확인해야 합니다.
